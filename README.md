# Hiring Web Platform

A web-based hiring platform that connects students with companies for recruitment opportunities.  
This platform helps companies post job openings and allows students to apply for jobs easily through an interactive and user-friendly interface.

## Features

- Student Registration & Login
- Company Registration & Login
- Job Posting by Companies
- Job Application by Students
- Resume Upload
- Dashboard for Students and Companies
- Search and Filter Jobs
- Secure Authentication System

## Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: PHP / Node.js / Java (Add your technology)
- Database: MySQL

## Project Objective

The main objective of this project is to simplify the hiring process between students and companies by providing a centralized online platform.

## Modules

### Student Module
- Create account
- View available jobs
- Apply for jobs
- Upload resume

### Company Module
- Register company
- Post job vacancies
- View student applications
- Manage hiring process
